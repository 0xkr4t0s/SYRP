# WP-2.1-05: syrp-audio-basics: VoicePool, lane-packed voices with note assignment, stealing and sleep

## Purpose
`VoicePool` from ADR 0003 D5 and master plan §5.8: polyphonic voices stored as `syrp_simd` lane packs, notes assigned to lanes, and a whole pack rendered per call. It is the native replacement for JUCE's `Synthesiser`; `syrp-compat-audio` (WP-1.9-02) builds `Synthesiser` and `SynthesiserVoice` on it, running one compat voice per lane of a scalar (`f32`) pool. The pool takes plain voice events, not MIDI, so it does not depend on `syrp-midi`; the compat layer and later the processor runtime translate MIDI into events. Delivery: 2–3 PRs (B1–B3, then B4–B6, then B7–B8).

## Behaviour
- B1. `trait Voice<S: Sample>: Send`: `prepare(sample_rate, max_frames, out_channels)`; `start(lane, &NoteStart)` where `NoteStart` has channel (1–16), note, velocity (0–1) and the channel's pitch-wheel and controller state at that moment; `stop(lane, velocity, allow_tail_off)`; `pitch_wheel(lane, value)` and `controller(lane, number, value)` with default no-ops; `render(&mut self, out: &mut [&mut [S]], frames)` writing one pack-wide block per output channel; `active(&self) -> S::Mask`, the lanes still sounding. A voice writes zeros in inactive lanes. Write a `SawVoice<S>` test voice (naive saw times a linear gate) in the tests.
- B2. `VoicePool<S, V: Voice<S>>`: `new(voices, factory)` allocates `ceil(voices / S::LANES)` packs and all scratch at construction; `prepare` forwards to every pack. `VoicePool<f32, V>` (one lane per pack) is the scalar path the compat layer uses, and `handle(lane)` returns a stable `VoiceHandle { pack, lane }` so code can address one voice directly (ADR 0003 D1).
- B3. Events: `render(&mut self, out: AudioBlockMut<f32>, events: &[VoiceEvent])` with events sorted by sample offset (`NoteOn`, `NoteOff`, `Sustain { channel, down }`, `Sostenuto`, `PitchWheel`, `Controller`, `AllNotesOff { channel: Option<u8> }`, `AllSoundOff`). The block is split at each event offset so events are sample-accurate, except that splits shorter than `set_minimum_subdivision(frames)` are merged forward, as `Synthesiser::setMinimumRenderingSubdivisionSize` documents. Each pack's lanes are summed into the output channels; the output is added to, not overwritten, and `render` never allocates (`syrp_rt::no_alloc` test).
- B4. Assignment: a `NoteOn` takes the lowest free lane (lowest pack, then lowest lane); a `NoteOn` for a channel and note already sounding stops that lane with tail-off and starts the note in a free lane (or the same lane if none is free). `NoteOff` stops every lane holding that channel and note, unless the channel's sustain pedal is down, in which case the lane is marked sustained and stopped when the pedal lifts. Sostenuto holds only the notes down when it was pressed. These rules follow the `Synthesiser` documentation where it decides them; the rest are Syrp's, documented, and listed for the differential harness.
- B5. Stealing: with every lane busy and stealing enabled (the default; `set_note_stealing(false)` drops the new note instead), the pool steals, in order of preference, the oldest released lane, then the oldest held lane that is not the lowest or highest held note when more than two are held, then the oldest held lane. A stolen lane is stopped without tail-off before the new note starts. Tests cover each tier.
- B6. Sleep (ADR 0003 D5): a pack whose `active` mask is empty is not rendered; a lane whose voice has stopped and reports inactive becomes free; `active_voices()` counts sounding lanes. A test with 64 voices in `F32x8` packs and 2 sounding notes shows that only one pack's `render` runs (the test voice counts calls).
- B7. ADR 0003 D7: the same event stream rendered by pools of `SawVoice<f32>`, `SawVoice<F32x4>` and `SawVoice<F32x8>` with the same voice count gives the same output within the `f32-arith` tolerance, and the same lane-assignment trace when the pack width divides the voice count. A proptest over random event streams checks that no note is lost or doubled: every started note ends by a matching note-off, an all-notes-off or a steal.
- B8. `benches/voice_pool.rs` counts instructions (Callgrind, same harness style as `crates/foundation/simd/benches/instructions.rs`) for 16 sounding `SawVoice` voices over 512 frames with `f32` versus `F32x8` packs; record the ratio in the module docs.

## Not in this WP
Stereo lane filling (four stereo voices in eight lanes) and MPE: each is a later WP. Per-channel processor duplication is in WP-1.9-02.

## Rules that apply to every WP
- Clean room: work only from this spec, the master plan (`docs/design/master-plan.md`) and public JUCE *documentation* for behaviour. Never fetch or recall JUCE source code.
- Name every test after the behaviour it proves, prefixed with its id, for example `b3_try_push_fails_when_full`.
- Run `cargo syrp wp show WP-2.1-05` first and `cargo syrp wp check WP-2.1-05` last. A PR is ready only when that command exits 0.
- Shared files (workspace `Cargo.toml`, CI, `deny.toml`) are not yours. If you need a new third-party dependency in `[workspace.dependencies]`, declare it with an explicit version in your crate's own `Cargo.toml` and list it in the PR front matter `deps_added`; the adversarial verifier reviews it.
